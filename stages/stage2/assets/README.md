# Stage 2 Sprites — Mission Preparation & Transit

This folder contains cleanroom equipment and module sprites for Level 2.

## Expected Sprite Files

All sprites should be transparent PNGs:

- `commander.png`: Crew commander sprite representation.
- `oxygen_tank.png`: Primary life-support oxygen storage tank.
- `water_recycler.png`: Closed-loop atmospheric and greywater recycler.
- `food_supply.png`: Calibrated nutritional mission payload.
- `medical_kit.png`: Emergency medical and surgical kit.
- `communication.png`: Deep-space communication transceiver.
- `power_unit.png`: Auxiliary power generation unit.
- `habitat_module.png`: Deployable transit habitat shelter module.
- `scientific_tools.png`: Surface and orbital analysis instrumentation.
- `rover.png`: Packed rover payload container.

## Updating Sprites via GitHub

1. Open this folder on GitHub (`stages/stage2/sprites/`).
2. Click **Add file** -> **Upload files**.
3. Upload your updated PNG image with the exact filename listed above.
4. Commit your changes.
