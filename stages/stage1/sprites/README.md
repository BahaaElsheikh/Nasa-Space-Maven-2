# Stage 1 Sprites — Rover Construction Workshop

This folder contains component sprites for Level 1 (Mars Rover Construction Workshop).

## Expected Sprite Files

All sprites should be transparent PNGs, recommended size 64x64 or 128x128 pixels (pixelated scaling supported):

- `chassis.png`: Rover chassis base structure.
- `wheels.png`: Mobility wheels / suspension system.
- `solar_panel.png`: Photovoltaic solar array.
- `camera.png`: Mastcam / navigation sensor mast.
- `antenna.png`: High-gain / low-gain communications antenna.

## Updating Sprites via GitHub

1. Open this folder on GitHub (`stages/stage1/sprites/`).
2. Click **Add file** -> **Upload files**.
3. Upload your updated PNG image with the exact filename listed above.
4. Commit your changes.
