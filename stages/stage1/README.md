# Stage 1: Rover Construction Workshop

Stage 1 guides the player through designing and assembling an exploratory Mars rover tailored for harsh planetary conditions.

## Subdirectories

- `cutscene/`: Narrative introduction slides (`1.png`, `2.png`, `3.png`), audio narration, and `story.json`.
- `sprites/`: Component sprites for the rover workshop (`chassis.png`, `wheels.png`, `solar_panel.png`, `camera.png`, `antenna.png`).
