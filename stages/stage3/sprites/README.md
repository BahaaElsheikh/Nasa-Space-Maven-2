# Stage 3 Sprites — Mars Habitat & Outpost Operations

This folder contains surface base and outpost operational sprites for Level 3.

## Expected Sprite Files

All sprites should be transparent PNGs:

- `habitat.png`: Primary pressurized Martian dome or habitat module.
- `solar_farm.png`: Surface photovoltaic array / power distribution grid.
- `water_source.png`: Subsurface ice extraction / water processing station.
- `oxygen_generator.png`: MOXIE / atmospheric oxygen generation facility.
- `storage.png`: Pressurized supply depot and resource silo.

## Updating Sprites via GitHub

1. Open this folder on GitHub (`stages/stage3/sprites/`).
2. Click **Add file** -> **Upload files**.
3. Upload your updated PNG image with the exact filename listed above.
4. Commit your changes.
