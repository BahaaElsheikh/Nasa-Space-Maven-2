# Stage 3 Cutscene Assets

This folder houses the visual and audio slides for Cutscene 3 (Mars Habitat / Outpost Operations).

## Expected Slide Files

- Images: `1.png`, `2.png`, `3.png`
- Audio (Voiceover/FX): `audio1.mp3`, `audio2.mp3`, `audio3.mp3`
- Story Manifest: `story.json`

## How to Edit Story Text via GitHub

1. Click on `story.json` in GitHub.
2. Click **Edit this file**.
3. Update slide titles and text in valid JSON.
4. Commit your changes.

## How to Replace Cutscene Slides via GitHub

1. Upload replacement images directly through GitHub's web interface.
2. Name them `1.png`, `2.png`, or `3.png`.
3. Commit the change.
