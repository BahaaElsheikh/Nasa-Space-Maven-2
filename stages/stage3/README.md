# Stage 3: Mars Habitat & Outpost Operations

Stage 3 focuses on landing site selection, environmental survival conditions, habitat deployment, and long-term base resource management on the Martian surface.

## Subdirectories

- `cutscene/`: Narrative transition slides (`1.png`, `2.png`, `3.png`), audio narration, and `story.json`.
- `sprites/`: Base infrastructure and outpost operation sprites (`habitat.png`, `solar_farm.png`, `water_source.png`, `oxygen_generator.png`, `storage.png`).
