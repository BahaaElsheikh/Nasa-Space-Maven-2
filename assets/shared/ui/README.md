# Shared UI Assets

This folder contains shared user interface elements, HUD frames, and border artwork.

## Expected Files

- `panel-frame.png`: Sci-fi terminal frame border.
- `button-frame.png`: Interactive button background and border.
- `hud-frame.png`: Viewport overlay border.
- `background.png`: Fallback dark space / Martian horizon texture.

All images should be in PNG format.
