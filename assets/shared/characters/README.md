# Shared Character Portraits

This folder contains high-resolution and pixel-art portrait assets for all crew members and the mission AI.

## Required Character Files

All portraits must be in **PNG format** with transparent backgrounds where applicable:

| Filename | Character Name | Role |
| :--- | :--- | :--- |
| `rodaina.png` | Rodaina | Commander |
| `bahaa.png` | Bahaa | Power / Systems Engineer |
| `hamdy.png` | Hamdy | Logistics Specialist |
| `mora.png` | Mora | Life Support Specialist |
| `alaa.png` | Alaa | Science / Geology Specialist |
| `nour.png` | Nour | Robotics Engineer |
| `mica.png` | MICA | AI Mission Guide (Autonomous System) |

> **Note**: MICA is an autonomous AI mission companion, distinct from the human crew members.

## How to Update via GitHub

1. Navigate to this folder on GitHub (`assets/shared/characters/`).
2. Click **Add file** -> **Upload files**.
3. Select your updated PNG image. Ensure the filename matches one of the filenames listed above (e.g., `rodaina.png`).
4. Commit the changes directly to `main`.
5. The game will automatically load the new portrait.
